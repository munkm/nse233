## Course content for NSE 233

Mathematical Methods for Nuclear Science and Engineering
Spring 2025

## Getting started

### First time setup

1. [Install Pixi](https://pixi.sh/) on your machine

> [!NOTE]
> You might need to restart your terminal or source your shell's configuration files for Pixi to become available.

> [!TIP]
> You might also want to enable [Pixi's autocompletion](https://pixi.sh/latest/advanced/installation/#autocompletion) for your shell.

2. Ensure Git is installed on your machine. If it isn't you, or you don't know, you can install it with Pixi with

```
pixi global install git
```

3. Clone your fork of this repository

```
git clone https://github.com/<your GitHub user name>/nse233.git
```

and navigate to that directory

```
# Linux and macOS
cd nse233
```

### Interacting with the course content

From the repository, run

```
pixi run start
```
